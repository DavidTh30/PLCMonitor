Variable names

PUT/GET only gives bytes. Names come from files exported from the PLC engineering software; they are kept next to the config.
  1. Data blocks: in the project tree select the data blocks (and their PLC data types) → right-click → Generate source from blocks → Including all dependent blocks (.db, .udt, .scl). STEP 7 classic: Generate source (.awl).
  2. Inputs, outputs, markers: open the PLC tag table → Export (.xlsx, .xml or .sdf), or a .csv with Name, Data Type, Logical Address, Comment.
  3. Give each data block its DB number below (a generated source has only the name). Numbers are filled in when the name is DB10 or the size matches one scanned DB.
