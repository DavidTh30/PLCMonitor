Looks for ISO-TCP PLCs (port 102), Modbus TCP (502), EtherNet/IP (44818), OPC UA (4840) and web (80/443) on every address. It only connects and reads; nothing is written.
PROFINET devices Finds PROFINET devices on this Ethernet segment, also ones without an IP address, and lets you set their IP address and name of station.
How to set up the Linux agent (no driver needed on this PC)

Windows can't send PROFINET DCP frames without a driver. A small Linux computer on the PROFINET network (industrial PC, Raspberry Pi, a laptop with Linux) can – PLC Monitor uses it as an agent:

  1. Copy plcmonitor-linux-amd64 (PC) or plcmonitor-linux-arm64 (Raspberry Pi 4/5) from the PLC Monitor folder to it.
  2. On it, run once: chmod +x plcmonitor-linux-* && ./plcmonitor-linux-amd64 install-agent
    It asks for the sudo password by itself, installs a service that starts at boot with only the raw-network permission (CAP_NET_RAW), and prints the address and token.
  3. Enter them above and press Connect. The adapter list then shows the Linux PC's adapters – pick the one wired to the PROFINET devices.

Firewall on the Linux PC: allow TCP 8095 (e.g. sudo ufw allow 8095/tcp). Remove: sudo s7monitor uninstall-agent.

The connection settings below are kept and used again when you turn the simulator off.

⚠ Enter the PLC's IP address. Without it PLC Monitor stays disconnected. Not sure? Use Topology → Scan to find PLCs on the network.

1200/1500-series: rack 0, slot 1 · 300-series: rack 0, slot 2 · 400-series: the CPU's slot.

⚠ Enter the PLC's OPC UA endpoint, e.g. opc.tcp://192.168.0.1:4840.

Tags are read by their node ID, so names come from the PLC and optimized data blocks work. Find and add them with File → PLC → PLC tags (OPC UA)…. In the PLC engineering software: CPU properties → OPC UA → Server → Activate OPC UA server, and select the variables (Accessible from HMI/OPC UA).

For RS485-to-Ethernet converters set to pass raw RTU frames ("transparent" / "none" mode, often port 502, 4001, 8899 or 23). If the gateway converts to Modbus TCP itself, choose Modbus TCP/IP instead. Its RS485 baud rate is set in the gateway.

USB-RS485 adapters show up as a COM port. Wire A/B (D+/D−) and GND; terminate both ends of a long bus with 120 Ω.

0 reads only adjacent addresses together, which suits devices that reject unmapped registers.

Name of station

PROFINET names: lower-case letters a–z, digits, “-” and “.”, e.g. plc-line1 or et200sp-3.cell2. It must match the name in the controller's project, or the controller won't find the device.

⚠ The device takes the new settings at once. Anything talking to it now – PLC program, HMI, this program – loses the connection. Many PLCs refuse when their IP address or name is set in the PLC project (then change it there), or while running.
