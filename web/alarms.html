Alarm messages

  • Each alarm watches one tag. It comes while its condition holds (after the delay) and goes when it stops.
  • Conditions: TRUE / FALSE for a Bool, bit n of a Byte / Word / DWord (alarm words), > >= < <= = <> a value, outside / inside a range.
  • Classes: fault alarm warning info. With Ack the alarm stays in the list until it is acknowledged.
  • Text placeholders: {value} the tag value when it came, {tag}, {limit}, {min}, {max}, {id}.
  • Signals: each tag runs simulated (toggle, bits, slider, ramp, sine, random) or live from the PLC.
  • Drag tags from the PLC Monitor tag list onto the alarms: a Bool gets TRUE, a Word / Byte / DWord gets bit 0, a number gets > 80.
  • Export CSV / Excel for the HMI; Import reads the same columns (ID, Class, Group, Tag, Condition, Delay ms, Ack, Text) and lists from other tools (Bit, Limit, Message …).
